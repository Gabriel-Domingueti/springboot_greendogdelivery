# 🌭 Green Dog Delivery - Estudos de Spring Boot

Este repositório contém o código-fonte do projeto **Green Dog Delivery**, desenvolvido como material de estudo prático para aprofundar e consolidar conhecimentos em desenvolvimento back-end e arquitetura de software com Java. 

A aplicação está a ser construída seguindo o passo a passo e as boas práticas propostas no livro **"Spring Boot: Acelere o desenvolvimento de microsserviços"** do autor Fernando Boaglio (Casa do Código).

## 🚀 Tecnologias e Ferramentas
* **Java** (JDK 21)
* **Spring Boot 3**
* **Spring Data JPA / Hibernate** (Mapeamento Objeto-Relacional)
* **H2 Database** (Banco de dados em memória para testes rápidos)
* **Thymeleaf & Thymeleaf Layout Dialect** (Template engine para renderização SSR)
* **Bootstrap 3 & jQuery** (Interface e estilização)
* **Maven** (Gerenciamento de dependências)
